# Static FSLTL placement package

`SS-KPHX-Static-FSLTL_cFxZl.rar` contains placement BGLs that reference external FSLTL aircraft libraries. It does not contain the aircraft geometry or textures required for a standalone RampReady runtime.

Keep this package isolated until an explicit, performance-budgeted atmosphere pass. Static aircraft must never occupy active pushback lanes, the A1 training stand, or the B15-to-A1 corridor.
