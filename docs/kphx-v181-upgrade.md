# KPHX v1.8.1 browser upgrade

Source archive: `unmlobo-kphx1-8-1_Mu9aq.zip`

The package supplies current KPHX airport records, 186 parking stands, 112 jetway placements, modern apron/painted-line data, and airport marking materials. Its terminal buildings and jetway models are MSFS stock assets and are not embedded in the archive, so RampReady uses the exact A/B placement records with browser-native Terminal 4 gate modules and jetways.

The first training corridor is anchored at A1 and includes both regional B15 positions:

- A1: training origin
- B15L: approximately 515 meters east in the source coordinate frame
- B15M: approximately 542 meters east in the source coordinate frame

Runtime scope in this pass:

- 58 exact Terminal 4 A/B parking positions
- 58 exact Terminal 4 A/B jetway placements
- textured/worn concrete ramp
- expansion joints, gate lead-ins and stop bars
- warm concrete terminal modules and facade glass
- glass jetway bridges, cabins, supports and readable gate signs
- airport-wide ADEX ground remains underneath for full KPHX coverage

The `SS-KPHX-Static-FSLTL` archive contains placement records only and depends on external FSLTL aircraft models. It is intentionally deferred as an optional atmosphere layer so it cannot block or interfere with training paths.
